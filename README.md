# Tamoji website

Public product, support and privacy pages for Tamoji. This repository contains only website content and an approved app icon, not the private application source or user saves.

Static HTML/CSS; no build or JavaScript dependencies. Publish `main` / repository root using GitHub Pages.

Support: support@picklz.app

Review the privacy page whenever the app SDKs, advertising/consent setup or data practices change. Keep App Store Connect URLs pointed at the published support/ and privacy/ pages.
